# Lab 1: Don’t Make Me Think!
### CS 355: User Interface and Experience
**Author:** Michael Ngo  

## Project Overview
This project is a single-page landing page designed for a **Greenhouse and Garden Club** workshop. The primary goal of the design is to reduce cognitive load and make the user's next step (registration) obvious, following the principles from Steve Krug's "Don't Make Me Think."

## Workshop Details
* **Topic:** Plant & Care Workshop
* **Target Audience:** SVC Students and Staff
* **Cost:** Free
* **Format:** In-person (SVC Greenhouse)

## Key UI/UX Features
* **Z-Pattern Layout:** Designed to support the natural scanning behavior of users.
* **Visual Grouping:** Logistical information (Date, Time, Location) is grouped to reduce "design cost" and interpretation time.
* **High-Contrast CTA:** The "Claim Your Free Flower Pot" button uses a terracotta orange to stand out against the garden-green theme.
* **Satisficing Support:** Minimalist form fields and value-driven labels help users reach their goal with the least amount of friction.
